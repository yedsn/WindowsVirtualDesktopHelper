# macOS 技术验证版

这是 Windows Virtual Desktop Helper 的独立 macOS 技术验证应用，用来验证：

- 从 macOS 原生 Space 读取桌面、当前桌面和窗口归属。
- 在菜单栏同时显示每个桌面的编号，点击图标直接切换桌面。
- 用当前桌面的高亮状态跟随系统切换。
- 在一个窗口中查看所有原生桌面及其应用窗口。
- 将一个已打开窗口移动到另一个桌面。
- 跳转到一个其他桌面的窗口并尝试激活它。

它不会影响 `Source/` 下的 Windows 应用，也不会自动移动任何窗口。

## 构建与运行

```bash
cd MacPrototype
./run.sh
```

开发时也可以只构建：

```bash
./build.sh
```

构建产物为 `MacPrototype/.build/WVDHMacPrototype.app`。首次使用“跳转并激活”时需要在系统设置中授予辅助功能权限。

测试“所有窗口”界面时可以直接打开：

```bash
./run.sh --show-overview
```

## 已使用的接口

桌面切换和窗口归属依赖隔离在 `SkyLightService.swift` 中的 SkyLight 私有接口。窗口列表使用 CoreGraphics，当前可见窗口的激活使用 Accessibility API。

已在 macOS 26.6.2（Apple M2、单显示器、自定义 SIP 配置）上验证菜单栏多图标、切换与高亮、跨桌面窗口列表、窗口移动、跳转并激活。接口包含私有 API，不能作为 Mac App Store 沙盒应用分发，也必须针对新的 macOS 版本重新验证。

## 本版边界

- 目标桌面必须已经存在；不会创建或删除原生 Space。
- 显示在所有桌面的窗口只列出一次，并禁止移动。
- 其他桌面的窗口可以枚举，但辅助功能通常只能在切换到该桌面后执行激活。
- 多显示器、桌面重排、注销重启、全屏 Space 和默认 SIP 环境仍需单独验证。
- 这是技术验证版，不包含 Windows 版的规则快照、清理锁定和一键清理移植。

## 本机验证记录（2026-10-30）

- 构建通过；独立应用已启动，Windows 的 Source/ 未改动。
- 5 个原生桌面对应 5 个菜单栏图标；点击切换并更新当前桌面高亮。
- 授予辅助功能和屏幕录制权限后，跨桌面应用及窗口标题可读取。
- 从概览选中临时测试窗口：桌面 5 → 桌面 1，重新枚举确认归属已改变，当前桌面仍为 5。
- 对该窗口执行“跳转并激活”：当前桌面变为 1。测试结束恢复桌面 5，关闭临时窗口。
- 旧的 SLSMoveWindowsToManagedSpace 在本机没有实际移动窗口。新路径使用 SLSBridgedMoveWindowsToManagedSpaceOperation，并解析 SkyLight 的内部符号发起操作；未找到该符号时回退旧接口，界面仍会校验实际窗口归属，不将发出请求当作成功。
- Native/SkyLightBridge.m 的 Mach-O 符号解析部分改编自 yabai，MIT 许可证保存在 Native/YABAI-LICENSE.txt。

这些结果仅覆盖本机环境，不证明默认 SIP、多显示器或其他 macOS 版本可用。规则与锁定不属于这个独立技术验证版。

## 权限与签名

“跳转并激活”需要辅助功能权限；CoreGraphics 窗口标题读取需要屏幕录制权限。权限由 macOS 按应用身份管理，修改签名后可能需要重新授权并重启应用。

构建脚本优先使用本机可用签名证书，可通过 WVDH_SIGN_IDENTITY 指定；没有证书时使用 ad-hoc 签名。稳定证书有助于权限持续生效，但本机验证不能保证每次更新后都保留授权。

## 关闭窗口

底部提供“关闭窗口”按钮，使用所选窗口的辅助功能关闭按钮。其他桌面的窗口会先切换到所在桌面。未保存内容由目标应用处理；窗口仍存在时只报告已请求关闭。

构建与移动复测通过。关闭最终验证尚未完成：图形会话截图全黑、辅助功能无法枚举界面，需恢复图形会话后继续验证。
