Back to [Home](https://github.com/dankrusi/WindowsVirtualDesktopHelper)

## Action Documentation

(as of v2.0)

The following actions are supported:

- ``Desktop1``
- ``Desktop2``
- ``Desktop3...``
- ``DesktopForward``
- ``DesktopBackward``
- ``PreviousDesktop``
- ``TaskView``

``TaskView`` opens Windows Task View using the same behavior as clicking the desktop number tray icon when Task View click handling is enabled.
